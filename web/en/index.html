Pin messages in a thread, like Telegram

Pins is a plugin for BB. Pin the messages that matter, yours or the agent's, and get back to them in one click: a pins bar sits above the thread, and every pin from every thread is listed on a page in the sidebar.

InstallFeatures

BB 0.50+ · MIT · data stays local

Features

📌

Pins in a thread

A Pin button on every message. Pin as many as you like; click again to unpin.

🔝

Bar on top

The thread shows a pin, a 2/5 counter and arrows. Click the text to scroll to the message. With no pins the bar takes no space.

🗂

Sidebar page

A Pins item in bb navigation: pins of all threads in groups, search, and a badge with the pin count.

🔎

Right panel tab

A list of pins from all threads with search and a "This thread" filter.

↪️

Jump to the message

Opens the thread and scrolls to the message, however far back it is.

🔒

Local

Pins live in the plugin database on your bb server, with a copy of the text. Nothing leaves your machine.

Install

bb plugin install git:https://github.com/yazydzhi/bb-plugin-pins.git

Requires BB 0.50 or newer. After install, messages get a Pin button and the sidebar gets a Pins item.

Limits

  • One pin per message: pinning another selection of the same message replaces the saved quote.
  • Cmd/Ctrl-click opens the thread in a split but does not scroll to the message.
  • Pins of deleted threads stay listed but cannot be opened.
